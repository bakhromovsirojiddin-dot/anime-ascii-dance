# 💃 Anime True-Color ASCII Video Player (Caramelldansen)

Консольный полноцветный 24-bit TrueColor ASCII-видеоплеер в терминале с синхронизированным воспроизведением музыки через Pygame (точь-в-точь как в вашем видео!).

Воспроизводит культовый танец **Caramelldansen** со световыми эффектами, персонажами и оригинальной шведской песней прямо в командной строке / терминале VS Code.

---

## 🚀 Особенности и архитектура

- **24-битный ANSI TrueColor:** каждый символ выводится со своим оригинальным цветом пикселя (`\033[38;2;R;G;Bm`).
- **Сверхбыстрый рендеринг через NumPy (RLE):** алгоритм группировки соседних символов одинакового цвета снижает нагрузку на терминал в 5 раз и выдает стабильные 30 FPS без задержек.
- **Плавность без мерцания:** вместо медленной очистки экрана (`cls`) используется мгновенное позиционирование курсора в начало экрана (`\033[H`).
- **Синхронизация звука и видео (A/V Sync):** встроенный движок отслеживает аудио-такт и при необходимости автоматически компенсирует кадры, чтобы танец никогда не отставал от музыки.
- **Адаптация под размер окна:** автоматически определяет ширину и высоту терминала с коррекцией соотношения сторон символов (шрифт в терминале в ~2 раза выше своей ширины).

## ⚡ Как запустить прямо сейчас

1. Откройте терминал (PowerShell или встроенный терминал VS Code):
   ```powershell
   cd C:\Users\User\.gemini\antigravity\scratch\anime-ascii-dance
   ```

2. Запустите плеер:
   ```bash
   python main.py
   ```

> [!TIP]
> Для максимального эффекта (как на видео):
> - Разверните терминал на весь экран или увеличьте окно терминала;
> - В терминале можно уменьшить размер шрифта клавишами `Ctrl + Минус` — разрешение картинки станет ещё более плотным и чётким!

## ⚙️ Дополнительные параметры

Вы можете запускать плеер с разными режимами отображения символов:

```bash
# Режим с детальным набором символов (по умолчанию, как на видео)
python main.py --charset detailed

# Режим блочной псевдографики (высокая четкость)
python main.py --charset blocks

# Режим со стандартными символами
python main.py --charset standard

# Запуск любого другого собственного видеофайла
python main.py path/to/another_video.mp4 --audio path/to/another_audio.mp3
```

Остановка воспроизведения: нажмите `Ctrl + C` в любой момент. Курсор и цвета терминала автоматически вернутся в исходное состояние.
